# Toto Microservice SDK

Welcome to Toto SDK for building microservices in the Toto Ecosystem! 

Wonder what the Toto Ecosystem system is? Check the [Toto page](https://github.com/nicolasances/toto). 

## What's the SDK about
The goal of this SDK is to provide a **Fast**, **Cloud-agnostic**, **Opinionated** path to building and deploying Microservices. 

The SDK covers aspects such as: 
* Creating and exposing APIs
* Interacting with PubSub and Queueing infrastructure
* Interacting with Storage, whether it's a database or cloud object storage
* Securing your service
* Handling Secrets
